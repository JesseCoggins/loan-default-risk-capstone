# Loan data source

`Loan Default Data.xlsx` is the workbook used for the WGU D606 capstone. The analysis starts with 148,670 records and 34 columns, selects the research-question predictors and uses complete cases. The public report describes the preparation and evaluation; no production lending outcomes are claimed.

The course materials reviewed identify the dataset and scenario but do not state an upstream redistribution license. The repository’s MIT license covers the project code, not a new license grant for third-party data. No claim that the records are synthetic is made.
